# История версий

## 1.1 — 2026-09-27

- Новый дизайн в стиле Material 3 с «жидким стеклом»: полупрозрачные карточки с бликом, плавающая панель сверху, цвета из обоев (Android 12+)
- Карточки «Процессор» (большая цифра загрузки, температура, столбики ядер) и «Память» (занято / кэш / подкачка), чипы со сводкой
- Список процессов карточками: значки приложений, точка состояния, справа — метрика по выбранной сортировке; чипы сортировки
- Плавная анимация показателей, стеклянные диалоги с размытием фона (Android 12+), новый оверлей
- Классическая таблица htop осталась — ⋮ → «Классическая таблица htop»
- Исправлено: на Android 15 верх экрана уходил под заголовок; длинные имена пользователей залезали на соседнюю колонку

## 1.0 — 2026-09-27

Первая версия.

- Список процессов в стиле htop: PID, пользователь, состояние, CPU %, память %, RES, потоки, время CPU; сортировка нажатием на колонку
- Метры: загрузка и частота каждого ядра, память, подкачка, задачи, нагрузка, время работы, температура CPU и батареи
- Режим root (KernelSU / Magisk / APatch) — все процессы и загрузка CPU; без root — память, частоты и температуры
- Подробности о процессе и действия: SIGTERM / SIGKILL / SIGSTOP / SIGCONT, остановка приложения, «О приложении»
- Плавающий оверлей поверх других окон с топом процессов
- Названия приложений вместо пакетов, поиск, настройки интервала и шрифта
- Интерфейс на русском и английском
