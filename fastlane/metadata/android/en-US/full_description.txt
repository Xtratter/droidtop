DroidTop shows what is running on your phone and how much it costs — inspired by the classic <b>htop</b>.

<b>Features</b>
<ul>
<li>htop-style meters: load and frequency of every CPU core, memory, swap (zram), tasks, load average, uptime, CPU and battery temperature</li>
<li>Process tree: who started whom, collapsible branches, parent and children of every process</li>
<li>Process list with PID, user, state, CPU %, memory %, resident memory, threads, CPU time; tap a column to sort</li>
<li>App names instead of package names, search by name, PID or user</li>
<li>Process details: command line, peak memory, swap usage, oom_score_adj</li>
<li>Threads of a process with live CPU %, open files and sockets with TCP/UDP addresses</li>
<li>Device info in the spirit of AIDA64: SoC and core clusters, memory, storage, display, GPU, battery health, cameras, sensors, temperatures</li>
<li>Record CPU and memory of a chosen app to a CSV file in the background</li>
<li>Copy a state summary, process details and lists to the clipboard</li>
<li>Actions: SIGTERM, SIGKILL, SIGSTOP/SIGCONT, force stop an app, open app info</li>
<li>Pinch to zoom: bigger or smaller text in the htop table, from 40 seconds to 20 minutes on charts</li>
<li>History charts of CPU, memory, GPU and battery power, plus CPU and memory of each process</li>
<li>GPU: load, frequency, model and temperature for Adreno and Mali (usually needs root)</li>
<li>Battery: power in watts, current, voltage, time left or time to full</li>
<li>Floating overlay above other apps: CPU, per-core bars, RAM and top processes; drag it anywhere, optionally let touches pass through</li>
</ul>

<b>Root mode</b>
Since Android 7 an app can only see its own processes, and since Android 8 overall CPU load is hidden. With Shizuku (no root) you get every process and CPU load too. Without root or Shizuku DroidTop shows memory, core frequencies and temperatures. With root (KernelSU, Magisk, APatch) you get every process, CPU load and all actions.
